# Student Performance Data Analysis

## Project Overview

This project analyzes student performance data using Python.

## Technologies Used

- Python
- Pandas
- Matplotlib

## Project Features

- Data cleaning
- Missing value handling
- Average marks calculation
- Student performance analysis
- Attendance visualization
- Bar charts

## Files

- `student_data.csv` - Original dataset
- `analysis.py` - Python analysis code
- `cleaned_student_data.csv` - Cleaned dataset
- `average_marks.png` - Average marks chart
- `attendance.png` - Attendance chart

## Conclusion

The project successfully cleans the student dataset, calculates average marks, identifies the top-performing student, and visualizes student attendance and performance.
